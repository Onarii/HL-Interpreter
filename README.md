# HL Interpreter (HLInt)

A simple interpreter for the hypothetical language "HL".

## Group Members
Ashton Castro
John Soriano

## How to Run
python HLInt_simple.py PROG1.HL

## Files
- HLInt_simple.py: the interpreter
- PROG1.HL, PROG2.HL, PROG3.HL: sample HL programs
- NOSPACES.TXT: source code with spaces removed
- RES_SYM.TXT: reserved words and symbols found
